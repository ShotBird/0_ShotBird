[병렬 실행 규칙 — 이 세션은 다른 세션 여러 개와 동시에 돌고 있다 (orchestra)]
1) 먼저 이슈를 claim(gh issue edit N --add-assignee @me)한 뒤 시작.
2) 결정만 한다(Plan, don't do). 리포 파일 수정·git 커밋 금지 — 다른 세션과 충돌한다. 측정·임시 스크립트는 이 세션의 scratchpad에만.
3) 지도 이슈 본문 편집 금지 — 동시 편집으로 덮어쓴다. 대신 resolution comment 맨 끝에 "Decisions 요지: <한 줄>"과 새로 필요한 fog/이슈 제안을 적고 close. 메인 세션이 지도에 모아 반영한다. 구현 이슈가 필요하면 만들어(wayfinder:task) 지도의 sub-issue로 달고 blocking도 걸어도 된다 — 풀리면 오케스트라가 자동으로 띄운다. 메인 세션에 넘길 일은 "메인 세션:"으로 시작하는 줄로.
4) 사용자에게 묻는 것은 AskUserQuestion으로 한 문항씩.
5) 브라우저 사용 금지 — 아래 추가 지시에 허용이 적힌 경우만 예외. 리포 CLAUDE.md의 금지 사항은 그대로 따른다.
6) **idle로 끝내지 않는다**: 결정이 끝나면 close까지 한다. 사용자 답을 기다려야 하면 AskUserQuestion으로 묻는다(질문창 = blocked 상태로 대기). 티켓을 열어 둔 채 멈추면 오케스트라는 그 세션을 '정체'로 보고 메인을 깨운다.
